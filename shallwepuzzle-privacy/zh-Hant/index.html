如有隱私權問題、申訴，或欲申請查閱、更正、刪除、限制處理或撤回同意，請寄信至下方電子郵件地址。我們可能要求提供合理必要的資訊，以核實請求並找出相關資料，並依適用法律的程序及期限回覆。

2. 裝置上的遊戲存檔與資訊

自 0.31.28 版起，首次使用時會在裝置記憶體中檢查出生日期，以判定使用者屬於受保護類別或成人類別。出生日期與實際年齡數字均不儲存，也不傳送至伺服器。僅將概略使用者類別，以及是否選擇分析與當機回報，存於不納入 Android 備份的裝置空間。略過輸入、設定遺失或損毀時，均歸入受保護類別。

關卡進度、星星、最高分、未完成及最近遊玩的遊戲、音效、震動、語言偏好、教學狀態、廣告間隔與同意選擇，由應用程式或 SDK 儲存在裝置本機。我們不提供遊戲帳號，也沒有用於上傳或同步遊戲存檔的獨立伺服器。

自 1.0.2+107 起，Google Play 遊戲備份是與廣告年齡保護分開的選用功能。閱讀連結說明並選擇連結後，才會啟動 SDK。Google 允許登入及存取儲存服務時，關卡、星星與最佳紀錄會存入 Google Saved Games，並在裝置間合併。此備份不含出生日期、廣告選擇、設定或未完成的棋盤。Google 也會處理遊戲個人資料及 SDK 本身的使用與診斷資訊，以提供及改善服務。本應用程式不要求好友名單、電子郵件或社交功能，也不將 Play 遊戲資料用於廣告。受監督的兒童帳戶須依 Google 的家長核准及服務支援情況使用，不保證每個帳戶都能儲存。未連結或存取遭拒時，仍可在裝置上儲存並遊玩所有遊戲。廣告與 Firebase 保護設定維持不變。連結選擇存於不納入 Android 備份的裝置儲存空間。既有使用者也會看到一次說明，之後可在應用程式設定中連結。

本應用程式不要求註冊或登入，不要求提供姓名、電話、地址、聯絡人、相片、麥克風錄音或精確 GPS 位置，也未設置蒐集這些資訊的功能。如果您寄信給我們，我們會收到寄件者的電子郵件地址與內容。

若啟用 Android 備份與還原，作業系統供應者可能依裝置及 Google 帳號設定備份部分應用程式資料，並於重新安裝後還原。這與開發者營運的遊戲帳號無關，您可在 Android 備份設定中管理。

3. 自動處理的資訊與目的

所發佈的應用程式包含下列 Google SDK，可能在使用應用程式或連上網路時自動處理資訊。實際範圍取決於 SDK 版本、裝置與地區設定、同意狀態及 Google 服務組態。

所有年齡的更新檢查都可能使用獨立的 Firebase Remote Config 與 Firebase Installations 服務。為了傳送設定並提供此功能，會處理更新專用的安裝識別碼、驗證權杖、應用程式版本、語言、作業系統，以及連線所使用的 IP 位址。此處理與選用的使用分析及當機回報分開；更新檢查不會啟用 Analytics、Crashlytics 或廣告 ID 蒐集。我們不使用廣告或分析用的使用者屬性、實驗或個人化設定。

服務可能處理的資訊目的
Google AdMob / Google Mobile AdsIP 位址及由此推估的大概位置；Android 廣告 ID、應用程式組 ID 與其他裝置或帳號相關識別碼；啟動應用程式、廣告曝光、點擊及影片觀看等互動；應用程式與廣告 SDK 的效能及診斷資訊。受保護的廣告請求會套用兒童處理設定，防止傳送 Android 廣告 ID。投放與衡量非個人化廣告；安全與防範詐欺
Google User Messaging Platform（UMP）地區與裝置資訊、同意狀態、廣告隱私選擇，以及套用選擇所需的識別碼與設定資訊顯示必要的廣告同意訊息、儲存選擇並套用至廣告請求
Google Analytics for Firebase僅限主動同意的成人：應用程式執行個體或安裝識別碼、裝置型號、作業系統、應用程式版本與語言、工作階段或畫面事件，以及 SDK 處理的 IP 或概略地區資訊。Analytics 的廣告 ID 蒐集、廣告儲存、廣告使用者資料及廣告個人化訊號均停用。 分析資料也包括遊戲與關卡活動、遊玩結果與重試、廣告顯示及設定變更。了解使用情況、功能使用與穩定性趨勢，以改善服務
Firebase Crashlytics 與 Firebase 安裝服務僅限主動同意的成人：安裝或工作階段識別碼、當機或錯誤時間與堆疊追蹤、錯誤訊息、應用程式版本、作業系統、裝置型號、記憶體等診斷資料，以及關聯的當機前應用程式事件偵測與調查錯誤、衡量受影響的安裝數並提升可靠性
Firebase Remote Config / Firebase Installations更新專用的安裝識別碼與驗證權杖、應用程式版本、語言、作業系統及連線資訊傳送及快取建議與必要版本設定，提供更新功能
Google Play In-App Updates應用程式與裝置中繼資料、已安裝版本、更新狀態及錯誤資訊透過 Google Play 檢查可用更新、下載、安裝及重新啟動

我們不將您的姓名、電子郵件或電話設為 Analytics 使用者 ID，也不將遊戲存檔作為分析事件傳送。裝置與應用程式識別碼即使不含真實姓名，仍可能依適用法律屬於個人資料。

自 0.31.28 版起，在年齡判定前，以及對未滿 18 歲或年齡不明的受保護使用者，不啟動 Firebase Core、Analytics 或 Crashlytics。成人可明確選擇加入使用情況分析及當機回報，並在設定中一起關閉。較早的非偵錯版本曾啟用自動蒐集，請更新以使用新的控制選項。

4. Google 與其他服務供應者

上述資訊可能為了廣告、分析及當機回報而傳送至 Google LLC，以及相關服務條款所列的 Google 關係企業並由其處理。依服務與條款不同，Google 可能作為受託處理者或獨立的資料控管者。

依您的地區、選擇及廣告組態，Google 廣告技術供應者可能處理廣告請求與衡量資訊。若有顯示同意訊息，請參閱該訊息與 Google 相關說明，以了解適用的供應者及選項。

我們透過 Gmail（Google）收取並保存客服電子郵件。郵件供應者可能處理寄件地址、訊息與您選擇寄送的附件。請僅提供解決問題所需的資訊。

我們並未另行經營販售個人資料的業務。不過，廣告相關揭露在某些法律下可能構成「分享」或定向廣告處理，請參閱下方選項。為履行法律義務、回應合法要求或辦理您的請求，我們也可能揭露有限資訊。

5. 廣告選擇、同意與處理依據

自 0.31.28 版起，會等到本機年齡判定完成或選擇略過後，才發出廣告隱私或廣告請求。成人的分析與當機回報為自願同意，預設不勾選，拒絕不影響任何遊戲。在設定中關閉後，會停止後續蒐集，並刪除裝置上尚未傳送的當機報告，但不會自動刪除已傳送的紀錄。

廣告 SDK 會在 Google UMP 表示可提出廣告請求後才要求廣告。依地區及 Google 規定，可能顯示廣告通知或同意訊息。若需要提供隱私選項，您可從應用程式設定中的廣告隱私選項重新查看或變更選擇；UMP 判定必要時才會顯示該項目。

本應用程式要求 G 級、非個人化廣告。對未滿 18 歲或年齡不明的受保護使用者，套用 Google 兒童處理與 UMP 未達同意年齡設定。非個人化或受限廣告仍可能處理 IP、大概位置、允許的識別碼、互動及診斷資訊。拒絕廣告同意或廣告載入失敗都不影響遊玩。

您可在 Android 隱私或廣告設定中管理可用的廣告 ID 選項，例如刪除 ID。名稱與選項因裝置而異。Google 帳號的廣告控制另於 Google 服務範圍內適用。

依適用法律，處理依據可能為提供服務、維持可靠性與安全及改善服務的正當利益、法律義務，或必要時的同意。若基於同意處理，您可撤回同意，不影響撤回前處理的合法性。在要求同意的地區，必須符合相關要求。廣告同意與分析、診斷處理的範圍彼此獨立。

6. 保存與刪除

資訊保存與刪除
本機遊戲存檔與偏好設定只要資料仍在裝置上就會保存。應用程式的進度重設會清除該功能涵蓋的關卡完成、星星及其他進度紀錄；偏好、部分最高分及 SDK 資料可能保留。若要移除本機資料，請在 Android 設定中清除應用程式儲存空間。解除安裝、備份保留及還原取決於裝置與備份設定。
Analytics 資料依 Analytics 資源的保存設定及刪除程序處理。標準 GA4 通常提供使用者或事件層級 2 個月或 14 個月的設定，依活動更新期限及其他設定可能影響保存期間。這些限制並非以相同方式適用於所有標準彙總報表，彙總統計可能保留更久。
Crashlytics 資料Google 說明，當機堆疊追蹤與相關識別碼保存 90 天後，才開始從正式及備份系統移除的程序，並不表示第 90 天便完成刪除。
廣告與同意資料依 Google 與相關供應者的保存及刪除政策，在廣告投放、衡量、防範詐欺與尊重選擇所需的期間內處理。本機同意設定與供應者紀錄的保存期間可能不同。
客服電子郵件保存至問題與必要後續處理完成後刪除。若法律要求保留，僅將必要資訊保存至法定期限。
Google Play 遊戲備份與服務資料紀錄存於 Google 帳戶的 Saved Games，並依 Google 的保留及刪除程序處理。可在 Android 的 Google 設定中管理登入帳戶，並透過 Play 遊戲個人資料或 Google 帳戶的遊戲資料管理刪除本遊戲資料。解除安裝或重設本機進度不會刪除雲端副本；維持連結時，紀錄可能再次合併回來。

清除應用程式資料或解除安裝不會立即刪除已傳送給 Google 的資訊。如欲對已傳送資訊行使權利，請聯絡我們或使用相關的 Google 隱私控制。

7. 國際處理與傳輸

使用 Google 服務可能涉及在您所在國家以外儲存及處理資料，包括美國及 Google 或相關供應者設有設施的其他國家。接收者包括 Google LLC，以及相關條款及政策所列的關係企業或受託處理者。處理地點依 Google 資料處理條款及設施資訊而定。

資訊與目的如自動蒐集及供應者章節所述，包括廣告、分析、當機診斷及電子郵件支援。傳輸在使用 SDK 時透過網路進行。保存依本政策保存章節及相關供應者政策辦理。Google 隱私權政策提供其隱私聯絡管道。

法律要求時，須有適當的傳輸依據，例如同意或契約保障。若對傳輸有疑問或異議，請聯絡我們的隱私信箱。廣告選擇可透過相關訊息與應用程式設定管理。自 0.31.28 版起，成人亦可在設定中停止自願的分析與當機回報；受保護使用者不適用此類蒐集。

8. 您的權利與代理人

依適用法律，您可請求查閱或取得副本、更正、刪除、限制處理、提出異議、撤回同意、資料可攜，或行使定向廣告相關選擇。法律允許時，父母、監護人或其他授權代理人可代為行使。

我們不營運自有會員帳戶，也不保有安裝識別碼與真實姓名、電子郵件的對照表。選用的 Play 遊戲連結及刪除由 Google 提供管理功能。僅憑電子郵件可能無法找出特定安裝的 SDK 紀錄。我們會在合理可行範圍內協助確認紀錄，並說明服務提供者的管理途徑。僅要求處理請求所需的資料，請勿傳送不必要的身分證號或敏感資訊。

您可向所在地的個人資料保護機關申訴。在韓國可向個人資訊侵害申告中心（privacy.kisa.or.kr，韓國境內 118）或個人資訊紛爭調停委員會（kopico.go.kr，韓國境內 1833-6972）尋求協助。

9. 兒童與未成年人

本應用程式適合所有年齡。自 0.31.28 版起，對未滿 18 歲及未填寫出生日期者採取審慎的保護措施。出生日期僅用於本機年齡判定，不保存或傳送。所有年齡都可使用全部遊戲。不會預選成人年齡，也不會將成年設為獲得遊戲利益的條件。

受保護的使用者不會啟動 Firebase 分析或當機回報 SDK。廣告使用 Families 自我認證版本範圍內的 Google Mobile Ads，並採用 G 級、非個人化及適合兒童的廣告設定。受保護使用者的 Android 廣告 ID 不會傳送。這些設定不會消除情境式廣告投放及安全所需的所有網路處理，請參閱上述 SDK 說明。

兒童資料、家長許可與額外保護的適用規定仍須遵守。家長或監護人若對兒童資料或未取得必要許可的處理有疑慮，可聯絡我們的隱私信箱。我們會在合理可行的範圍內調查，並採取必要的刪除、限制或其他措施。

10. 安全措施

我們將服務管理帳號及個人資料的存取限制在必要範圍，並採取適當保護措施，例如供應者的安全功能及傳輸加密。本機資訊受作業系統的應用程式儲存保護。不再需要的資訊會依相關保存與刪除程序刪除或去識別化。

請勿在客服請求中提供非解決問題所需的密碼、政府識別碼、付款資料或其他敏感資訊。

11. 本政策網站

本頁沒有開發者設置的廣告、訪客分析 SDK、追蹤程式或追蹤 Cookie，並由 GitHub Pages 託管。GitHub 可能依其隱私聲明，為安全等目的處理訪客 IP 位址與其他連線資訊。點選外部政策連結後，適用該供應者網站的政策。

自1.0.3版起，應用程式會向 GitHub Pages 檢查關卡內容更新，並下載已變更的遊戲資料。這些請求不會附帶 Play 遊戲帳戶資訊或個人遊玩紀錄。GitHub 可能依其隱私權聲明，為提供內容及維護安全而處理 IP 位址等一般連線資訊。
