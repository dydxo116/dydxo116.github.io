အသက်အရွယ်တိုင်းတွင်၊ အပ်ဒိတ်စစ်ဆေးမှုများသည် သီးခြား Firebase အဝေးထိန်းစနစ်နှင့် Firebase တပ်ဆင်ခြင်းဝန်ဆောင်မှုများကို အသုံးပြုနိုင်ပါသည်။ အပ်ဒိတ်-သတ်သတ်မှတ်မှတ် တပ်ဆင်မှုအမှတ်အသားနှင့် စစ်မှန်ကြောင်းအထောက်အထားပြ တိုကင်၊ အက်ပ်ဗားရှင်း၊ ဘာသာစကား၊ လည်ပတ်မှုစနစ်နှင့် ချိတ်ဆက်မှုအတွက် အသုံးပြုသည့် IP လိပ်စာတို့ကို စီစဉ်သတ်မှတ်ပြီး ဤအင်္ဂါရပ်ကို လုပ်ဆောင်ရန်အတွက် စီမံဆောင်ရွက်ထားပါသည်။ ၎င်းသည် ရွေးချယ်နိုင်သော ခွဲခြမ်းစိတ်ဖြာမှုနှင့် ပျက်စီးမှုအစီရင်ခံခြင်းမှ သီးခြားဖြစ်သည်။ အပ်ဒိတ်များကိုစစ်ဆေးခြင်းသည် Analytics၊ Crashlytics သို့မဟုတ် ကြော်ငြာ ID စုဆောင်းခြင်းကို ဖွင့်မထားပါ။ ကျွန်ုပ်တို့သည် ဤစစ်ဆေးမှုများအတွက် ကြော်ငြာ သို့မဟုတ် ခွဲခြမ်းစိတ်ဖြာမှုအသုံးပြုသူ၏ ဂုဏ်သတ္တိများ၊ စမ်းသပ်မှုများ သို့မဟုတ် ပုဂ္ဂိုလ်ရေးသီးသန့်ပြုလုပ်ခြင်းကို မသုံးပါ။

ဝန်ဆောင်မှုလုပ်ဆောင်နိုင်သော အချက်အလက်ရည်ရွယ်ချက်
Google AdMob / Google မိုဘိုင်းကြော်ငြာIP လိပ်စာနှင့် ၎င်းမှ ခန့်မှန်းထားသော အနီးစပ်ဆုံးတည်နေရာ၊ Android ကြော်ငြာ ID၊ အက်ပ်သတ်မှတ် ID နှင့် အခြားစက်ပစ္စည်း/အကောင့်ဆိုင်ရာ သတ်မှတ်ဖော်ပြချက်များ၊ အက်ပ်စတင်ခြင်းများ၊ ကြော်ငြာအမြင်များ၊ ကလစ်များနှင့် ဗီဒီယိုကြည့်ရှုမှုများကဲ့သို့သော အပြန်အလှန်တုံ့ပြန်မှုများ၊ အက်ပ်နှင့် ကြော်ငြာ SDK စွမ်းဆောင်ရည်နှင့် ရောဂါရှာဖွေမှုများ (ကာကွယ်ထားသော ကြော်ငြာတောင်းဆိုမှုများသည် ကလေးကုသမှုကို သက်ရောက်စေပြီး Android ကြော်ငြာ ID ၏ ကူးစက်ခြင်းကို တားဆီးပါသည်။)သီးသန့်မဟုတ်သော ကြော်ငြာများကို ပေးပို့ခြင်းနှင့် တိုင်းတာခြင်း၊ လုံခြုံရေးနှင့် လိမ်လည်မှု ကာကွယ်ရေး
Google User Messaging Platform (UMP)ဒေသဆိုင်ရာနှင့် စက်ပစ္စည်းအချက်အလက်၊ ခွင့်ပြုချက်အခြေအနေနှင့် ကြော်ငြာကိုယ်ရေးကိုယ်တာရွေးချယ်မှုများနှင့်လိုအပ်သော ကြော်ငြာခွင့်ပြုချက်စာတိုများကို တင်ပြပါ၊ ရွေးချယ်မှုများကို သိမ်းဆည်းပြီး ၎င်းတို့ကို ကြော်ငြာတောင်းဆိုမှုများ
Google Analytics အတွက် Firebaseပါဝင်သည့် အရွယ်ရောက်ပြီးသူများအတွက်- အက်ပ်-အင်စတီကျရှင်း/ထည့်သွင်းမှု ခွဲခြားသတ်မှတ်မှုများ၊ စက်ပစ္စည်းမော်ဒယ်၊ လည်ပတ်မှုစနစ်၊ အက်ပ်ဗားရှင်းနှင့် ဘာသာစကား၊ စက်ရှင်/မျက်နှာပြင် ဖြစ်ရပ်များနှင့် SDK-စီမံဆောင်ရွက်ထားသော IP/အထွေထွေ ဒေသဆိုင်ရာ အချက်အလက်။ Analytics ကြော်ငြာ-ID စုဆောင်းမှု၊ ကြော်ငြာသိုလှောင်မှု၊ ကြော်ငြာ-အသုံးပြုသူ-ဒေတာနှင့် ကြော်ငြာ-ကိုယ်ရေးကိုယ်တာအချက်ပြမှုများကို ပိတ်ထားသည်။ ဂိမ်းနှင့် အဆင့် လုပ်ဆောင်ချက်၊ ကစားရလဒ်နှင့် ပြန်လည်ကြိုးစားမှု၊ ကြော်ငြာပြသမှုနှင့် ဆက်တင်ပြောင်းလဲမှုတို့ကိုလည်း ခွဲခြမ်းစိတ်ဖြာပါသည်။အသုံးပြုမှု၊ အင်္ဂါရပ်အသုံးပြုမှုနှင့် တည်ငြိမ်မှုလမ်းကြောင်းများကို နားလည်ပြီး
Firebase Crashlytics နှင့် Firebase တပ်ဆင်ခြင်းဝန်ဆောင်မှုများပါဝင်သည့် အရွယ်ရောက်ပြီးသူများအတွက်- တပ်ဆင်ခြင်း/စက်ရှင်သတ်မှတ်မှုစနစ်များ၊ ပျက်စီးမှု/အမှားအယွင်းအချိန်များနှင့် အစုလိုက်ခြေရာခံများ၊ အမှားမက်ဆေ့ချ်များ၊ အက်ပ်ဗားရှင်း၊ လည်ပတ်မှုစနစ်၊ စက်မော်ဒယ်၊ မှတ်ဉာဏ်နှင့် ဆက်စပ်ရောဂါရှာဖွေမှုများ၊ နှင့် ချိတ်ဆက်ထားသော အကြိုပျက်စီးမှုအက်ပ်ဖြစ်ရပ်များအမှားအယွင်းများကို ရှာဖွေပြီး စုံစမ်းစစ်ဆေးခြင်း၊ ထိခိုက်သည့် တပ်ဆင်မှုများကို တိုင်းတာပြီး
Firebase Remote Config / Firebase ထည့်သွင်းမှုများအပ်ဒိတ်-သတ်သတ်မှတ်မှတ် တပ်ဆင်မှုအမှတ်အသားနှင့် အထောက်အထားစိစစ်ခြင်းတိုကင်၊ အက်ပ်ဗားရှင်း၊ ဘာသာစကား၊ လည်ပတ်မှုစနစ်နှင့် ချိတ်ဆက်မှုအချက်အလက်အကြံပြုထားသော အက်ပ်ဗားရှင်း ဆက်တင်များ ပေးပို့ခြင်းနှင့် ကက်ရှ်လုပ်ခြင်း နှင့်
Google Play အက်ပ်အတွင်း အပ်ဒိတ်များအက်ပ်နှင့် စက်ပစ္စည်း မက်တာဒေတာ၊ ထည့်သွင်းထားသောအက်ပ်ဗားရှင်း၊ အဆင့်မြှင့်တင်မှု အခြေအနေနှင့် အမှားအယွင်း အချက်အလက်Google Play မှတစ်ဆင့် အပ်ဒိတ်ရရှိနိုင်မှုကို စစ်ဆေးခြင်း၊

ကျွန်ုပ်တို့သည် သင့်အမည်၊ အီးမေးလ်လိပ်စာ သို့မဟုတ် တယ်လီဖုန်းနံပါတ်ကို Analytics အသုံးပြုသူ ID အဖြစ် သတ်မှတ်ခြင်း သို့မဟုတ် ခွဲခြမ်းစိတ်ဖြာမှုဖြစ်ရပ်များအဖြစ် ဂိမ်းသိမ်းဆည်းခြင်းဖိုင်များကို ထုတ်လွှင့်ခြင်းမပြုပါ။ စက်ပစ္စည်းနှင့် အက်ပ်သတ်မှတ်ချက်များသည် သင့်အမည်ရင်းမဟုတ်သည့်တိုင် တည်ဆဲဥပဒေအောက်တွင် ကိုယ်ရေးကိုယ်တာဒေတာအဖြစ် ဆက်လက်ရှိနေနိုင်ပါသည်။

Firebase Core၊ ပိုင်းခြားစိတ်ဖြာချက် သို့မဟုတ် Crashlytics သို့မဟုတ် 18 သို့မဟုတ် အသက်မသိရသေးသော အသုံးပြုသူများအတွက် မစတင်ပါ။ အရွယ်ရောက်ပြီးသူများသည် သုံးစွဲမှုပိုင်းခြားစိတ်ဖြာချက်နှင့် ပျက်စီးမှုသတင်းပို့ခြင်းတွင် ပြတ်သားစွာရွေးချယ်နိုင်ပြီး နှစ်ခုလုံးကို ဆက်တင်များတွင် အတူတကွပိတ်နိုင်သည်။

အက်ပ်သည် အသက်အရွယ်အားလုံးအတွက်ဖြစ်သည်။ 18 အောက်တွင် အသုံးပြုသူများနှင့် မွေးသက္ကရာဇ်မထည့်သော သုံးစွဲသူများအတွက် ရှေးရိုးဆန်သော ကာကွယ်မှုများကို သက်ရောက်သည်။ မွေးရက်များကို ဒေသန္တရ အသက် ဆုံးဖြတ်ချက်အတွက်သာ အသုံးပြုသည်၊ သိမ်းဆည်းခြင်း သို့မဟုတ် ကူးစက်ခြင်း မရှိပါ။ ဂိမ်းအားလုံးသည် အသက်အရွယ်တိုင်းတွင် ရရှိနိုင်သည်။ အရွယ်ရောက်ပြီးသူ၏အသက်ကို ကြိုတင်ရွေးချယ်ထားခြင်း သို့မဟုတ် ဂိမ်းအကျိုးခံစားခွင့်များအတွက် အခြေအနေတစ်ရပ်အဖြစ် ဖော်ပြထားခြင်းမရှိပါ။

ကာကွယ်မှုလိုအပ်သော အသုံးပြုသူများအတွက် Firebase အသုံးပြုမှု ခွဲခြမ်းစိတ်ဖြာခြင်းနှင့် အက်ပ်ပျက်ကျမှု အစီရင်ခံသည့် SDK များကို မစတင်ပါ။ ကြော်ငြာများတွင် Families ကိုယ်တိုင်အသိအမှတ်ပြုထားသော ဗားရှင်းအတွင်းရှိ Google Mobile Ads ကို အသုံးပြုပြီး G အဆင့်၊ ကိုယ်ပိုင်အလိုက်ပြင်ဆင်မှုမရှိခြင်းနှင့် ကလေးများအတွက် သတ်မှတ်ထားသော ကြော်ငြာဆက်တင်များကို အသုံးပြုသည်။ ကာကွယ်မှုလိုအပ်သော အသုံးပြုသူများ၏ Android ကြော်ငြာ ID ကို မပို့ပါ။ ဤဆက်တင်များကြောင့် အကြောင်းအရာအလိုက် ကြော်ငြာပြသခြင်းနှင့် လုံခြုံရေးအတွက် လိုအပ်သော ကွန်ရက်ဒေတာလုပ်ဆောင်မှုအားလုံး ပျောက်ကွယ်သွားခြင်းမရှိပါ။ အထက်ပါ SDK အချက်အလက်ကို ကြည့်ပါ။

ကလေးများ၏ အချက်အလက်၊ မိဘခွင့်ပြုချက်နှင့် အပိုအကာအကွယ်များဆိုင်ရာ သက်ဆိုင်သည့် စည်းမျဉ်းများ ရှိနေသေးပါသည်။ ကလေး၏အချက်အလက် သို့မဟုတ် လိုအပ်သောခွင့်ပြုချက်မရှိဘဲ လုပ်ဆောင်ခြင်းနှင့်ပတ်သက်၍ သက်ဆိုင်သည့်မိဘများ သို့မဟုတ် အုပ်ထိန်းသူများသည် ကျွန်ုပ်တို့၏ကိုယ်ရေးကိုယ်တာအီးမေးလ်ကို ဆက်သွယ်နိုင်ပါသည်။ ကျွန်ုပ်တို့သည် ကျိုးကြောင်းဆီလျော်စွာ ဖြစ်နိုင်သည့်နေရာကို စုံစမ်းပြီး လိုအပ်သော ပယ်ဖျက်မှု၊ ကန့်သတ်ချက် သို့မဟုတ် အခြားအစီအမံများကို လုပ်ဆောင်ပါမည်။

10။ လုံခြုံရေး

ကျွန်ုပ်တို့သည် လိုအပ်သည့်အရာများတွင် ဝန်ဆောင်မှုစီမံခန့်ခွဲရေးအကောင့်များနှင့် ကိုယ်ရေးကိုယ်တာဒေတာများကို ဝင်ရောက်ကြည့်ရှုခွင့်ကို ကန့်သတ်ထားပြီး ဝန်ဆောင်မှုပေးသူလုံခြုံရေးအင်္ဂါရပ်များနှင့် အသွင်ဝှက်ခြင်းကဲ့သို့သော သင့်လျော်သောအကာအကွယ်များကို အသုံးပြုပါသည်။ ဒေသဆိုင်ရာ အချက်အလက်များသည် လည်ပတ်မှုစနစ်၏ အက်ပ်သိုလှောင်မှု အကာအကွယ်များပေါ်တွင် မူတည်ပါသည်။ မလိုအပ်တော့သော အချက်အလက်များကို သက်ဆိုင်ရာ ထိန်းသိမ်းခြင်းနှင့် ဖျက်ခြင်းဆိုင်ရာ လုပ်ထုံးလုပ်နည်းများအောက်တွင် ဖျက်ပစ်ခြင်း သို့မဟုတ် ဖော်ထုတ်ခြင်းအား ဖယ်ရှားလိုက်ပါသည်။

ပံ့ပိုးမှုတောင်းဆိုမှုကို ဖြေရှင်းရန် မလိုအပ်သော စကားဝှက်များ၊ အစိုးရသတ်မှတ်မှုစနစ်များ၊ ငွေပေးချေမှုအသေးစိတ်များ သို့မဟုတ် အခြားအရေးကြီးသော အချက်အလက်များ မပါဝင်ပါနှင့်။

11။ ဤမူဝါဒဝဘ်ဆိုဒ်

ဤစာမျက်နှာတွင် ဆော့ဖ်ဝဲထည့်သွင်းထားသော ကြော်ငြာများ၊ လည်ပတ်သူ ခွဲခြမ်းစိတ်ဖြာမှု SDKs၊ script များကို ခြေရာခံခြင်း သို့မဟုတ် ခြေရာခံခြင်း cookies များ မပါဝင်ပါ။ ၎င်းကို GitHub Pages တွင် လက်ခံကျင်းပသည်။ GitHub သည် ၎င်း၏ကိုယ်ပိုင်ကိုယ်ရေးကိုယ်တာထုတ်ပြန်ချက်အောက်တွင် လုံခြုံရေးနှင့်ဆက်စပ်သောရည်ရွယ်ချက်များအတွက် ဧည့်သည် IP လိပ်စာများနှင့် အခြားချိတ်ဆက်မှုအချက်အလက်များကို လုပ်ဆောင်နိုင်သည်။ ပြင်ပမူဝါဒလင့်ခ်ကို လိုက်နာခြင်းဖြင့် ထိုဝန်ဆောင်မှုပေးသူ၏ ဝဘ်ဆိုက်နှင့် မူဝါဒများဆီသို့ ခေါ်ဆောင်သွားပါသည်။

အက်ပ်သည် အဆင့်အကြောင်းအရာမွမ်းမံမှုများနှင့် ဒေါင်းလုဒ်ပြောင်းထားသော ဂိမ်းဒေတာအတွက် GitHub Pages စစ်ဆေးသည်။ ဤတောင်းဆိုချက်များတွင် Play Games အကောင့်အချက်အလက် သို့မဟုတ် ကိုယ်ရေးကိုယ်တာဂိမ်းကစားခြင်းမှတ်တမ်းများ မပါဝင်ပါ။ GitHub သည် ၎င်း၏ကိုယ်ပိုင်ကိုယ်ရေးကိုယ်တာထုတ်ပြန်ချက်အောက်တွင် အကြောင်းအရာကိုပေးပို့ရန်နှင့် လုံခြုံစေရန်အတွက် IP လိပ်စာများနှင့် အခြားပုံမှန်ချိတ်ဆက်မှုအချက်အလက်များကို လုပ်ဆောင်နိုင်သည်။
