1. பொறுப்பாளர் மற்றும் தொடர்பு

சேவையின் பெயர் ShallWePuzzle, Android தொகுப்புப் பெயர் kr.shall.we.puzzle. ஆப்ஸின் தனிப்பட்ட தரவுக் கையாளுதலுக்கும் தனியுரிமைக் கேள்விகளுக்கும் ShallWePuzzle டெவலப்பர் பொறுப்பாவார்.

தனியுரிமைக் கேள்விகள், புகார்கள், அணுகல், திருத்தம், நீக்கம், கட்டுப்பாடு அல்லது ஒப்புதல் திரும்பப் பெறுதல் தொடர்பான கோரிக்கைகளைக் கீழே உள்ள மின்னஞ்சலுக்கு அனுப்புங்கள். கோரிக்கையைச் சரிபார்க்கவும் தொடர்புடைய தகவலைக் கண்டறியவும் நியாயமாகத் தேவையான தகவலைக் கேட்கலாம்; பொருந்தும் சட்டத்தின் நடைமுறைகள் மற்றும் காலவரம்புகளின்படி பதிலளிப்போம்.

2. கேம் சேமிப்புகள் மற்றும் சாதனத்தில் உள்ள தகவல்

முதல் பயன்பாட்டின்போது, பயனர் பாதுகாக்கப்பட்ட வகையா வயதுவந்தோர் வகையா என்பதைத் தீர்மானிக்க, பிறந்த தேதி சாதன நினைவகத்தில் மட்டுமே சரிபார்க்கப்படும். பிறந்த தேதியும் எண் வயதும் சேமிக்கப்படுவதில்லை, சர்வருக்கு அனுப்பப்படுவதில்லை. பொதுவான பயனர் வகையும் விருப்பத்தேர்வான பகுப்பாய்வு/செயலிழப்பு அறிக்கைத் தேர்வும் மட்டுமே Android காப்புப்பிரதியிலிருந்து விலக்கப்பட்ட சாதனச் சேமிப்பகத்தில் வைக்கப்படும். தேதியைத் தவிர்த்தாலோ அமைப்புகள் இல்லாமலோ சிதைந்தோ இருந்தாலோ பாதுகாக்கப்பட்ட வகை பயன்படுத்தப்படும்.

நிலை முன்னேற்றம், நட்சத்திரங்கள், அதிகபட்ச மதிப்பெண்கள், முடிக்காத கேம்கள், சமீபத்தில் விளையாடிய கேம்கள், ஒலி, அதிர்வு, மொழி அமைப்புகள், பயிற்சி நிலை, விளம்பர இடைவெளிகள், ஒப்புதல் தேர்வுகள் ஆகியவை ஆப்ஸ் அல்லது SDK-இன் சாதனச் சேமிப்பகத்தில் சேமிக்கப்படும். கேம் சேமிப்புக் கோப்புகளைப் பதிவேற்றி ஒத்திசைக்கும் கேம் கணக்கையோ தனி சர்வரையோ நாங்கள் வழங்குவதில்லை.

Google Play Games காப்புப்பிரதி விருப்பத்தேர்வானது; விளம்பரத்துக்கான வயதுப் பாதுகாப்பிலிருந்து தனியானது. இணைப்பு அறிவிப்பைப் படித்து இணைக்கத் தேர்ந்தெடுத்த பிறகே SDK தொடங்கும். Google உள்நுழைவும் சேமிப்பக அணுகலும் அனுமதிக்கப்பட்டால், நிலைகள், நட்சத்திரங்கள், சிறந்த பதிவுகள் Google Saved Games-இல் சேமிக்கப்பட்டு சாதனங்களுக்கு இடையே ஒன்றிணைக்கப்படும். பிறந்த தேதி, விளம்பரத் தேர்வுகள், அமைப்புகள், முடிக்காத பலகைகள் இந்தக் காப்புப்பிரதியில் சேராது. சேவையை வழங்கவும் மேம்படுத்தவும் Google, Play Games சுயவிவரத்தையும் SDK-இன் சொந்தப் பயன்பாடு மற்றும் கண்டறிதல் தரவையும் கையாளும். இந்த ஆப்ஸ் நண்பர்கள், மின்னஞ்சல் அல்லது சமூக அம்சங்களைக் கோருவதில்லை; Play Games தரவை விளம்பரத்துக்குப் பயன்படுத்துவதில்லை. மேற்பார்வையிடப்படும் குழந்தைக் கணக்குகள் Google-இன் பெற்றோர் ஒப்புதல் மற்றும் சேவை ஆதரவைப் பொறுத்தவை; எல்லாக் கணக்குகளிலும் சேமிப்பு உறுதியில்லை. இணைக்காவிட்டாலும் அணுகல் மறுக்கப்பட்டாலும் எல்லா கேம்களையும் சாதனச் சேமிப்புகளுடன் விளையாடலாம். பாதுகாக்கப்பட்ட விளம்பர மற்றும் Firebase அமைப்புகள் தொடர்ந்து பொருந்தும். காப்புப்பிரதித் தேர்வு Android காப்புப்பிரதியிலிருந்து விலக்கப்பட்ட சாதனச் சேமிப்பகத்தில் வைக்கப்படும். ஏற்கெனவே உள்ள பயனர்களும் அறிவிப்பை ஒருமுறை பார்ப்பார்கள்; பின்னர் ஆப்ஸ் அமைப்புகளில் இணைக்கலாம்.

ஆப்ஸுக்குப் பதிவு அல்லது உள்நுழைவு தேவையில்லை. உங்கள் பெயர், தொலைபேசி எண், முகவரி, தொடர்புகள், புகைப்படங்கள், மைக்ரோஃபோன் பதிவுகள் அல்லது துல்லியமான GPS இருப்பிடத்தைச் சமர்ப்பிக்கக் கேட்பதில்லை; அவற்றைச் சேகரிக்கும் அம்சங்களும் இல்லை. நீங்கள் எங்களுக்கு மின்னஞ்சல் அனுப்பினால், உங்கள் அனுப்புநர் மின்னஞ்சல் முகவரியையும் செய்தியையும் பெறுவோம்.

Android காப்புப்பிரதி மற்றும் மீட்டமைப்பு இயக்கத்தில் இருந்தால், உங்கள் சாதனம் மற்றும் Google கணக்கு அமைப்புகளைப் பொறுத்து, சில ஆப்ஸ் தரவை இயக்க முறைமை வழங்குநர் காப்புப்பிரதி எடுத்து, மீண்டும் நிறுவிய பின் மீட்டமைக்கலாம். இது டெவலப்பர் இயக்கும் கேம் கணக்கிலிருந்து தனியானது. Android காப்புப்பிரதி அமைப்புகளில் இதை நிர்வகிக்கலாம்.

3. தானாகக் கையாளப்படும் தகவல் மற்றும் நோக்கம்

வெளியிடப்பட்ட ஆப்ஸில் கீழே உள்ள Google SDK-கள் உள்ளன. நீங்கள் ஆப்ஸைப் பயன்படுத்தும்போது அல்லது நெட்வொர்க்குடன் இணையும்போது அவை தகவலைத் தானாகக் கையாளலாம். சரியான வரம்பு SDK பதிப்புகள், சாதன மற்றும் பிராந்திய அமைப்புகள், ஒப்புதல் நிலை, Google சேவை உள்ளமைவு ஆகியவற்றைப் பொறுத்தது.

எல்லா வயதினருக்கும், புதுப்பிப்புச் சரிபார்ப்புகள் தனியான Firebase ரிமோட் கான்ஃபிக் மற்றும் Firebase Installations சேவைகளைப் பயன்படுத்தலாம். உள்ளமைவை வழங்கவும் இந்த அம்சத்தை இயக்கவும், புதுப்பிப்புக்கு மட்டுமான நிறுவல் அடையாளங்காட்டி மற்றும் அங்கீகார டோக்கன், ஆப்ஸ் பதிப்பு, மொழி, இயக்க முறைமை, இணைப்புக்குப் பயன்படும் IP முகவரி ஆகியவை கையாளப்படும். இது விருப்பத்தேர்வான பகுப்பாய்வு மற்றும் செயலிழப்பு அறிக்கையிலிருந்து தனியானது; புதுப்பிப்புகளைச் சரிபார்ப்பதால் Analytics, Crashlytics அல்லது விளம்பர ID சேகரிப்பு இயங்காது. இந்தச் சரிபார்ப்புகளுக்கு விளம்பர அல்லது பகுப்பாய்வுப் பயனர் பண்புகள், சோதனைகள் அல்லது தனிப்பயனாக்கத்தைப் பயன்படுத்துவதில்லை.

பொருந்தும் சட்டத்தைப் பொறுத்து, செயலாக்கம் சேவையை வழங்குதல், சேவை நம்பகத்தன்மை, பாதுகாப்பு, மேம்பாடு தொடர்பான நியாயமான நலன்கள், சட்டக் கடமைகள், அல்லது தேவைப்படும் இடங்களில் ஒப்புதல் ஆகியவற்றை அடிப்படையாகக் கொண்டது. ஒப்புதலை அடிப்படையாகக் கொண்ட செயலாக்கத்துக்கு, முந்தைய செயலாக்கத்தின் சட்டப்பூர்வத்தன்மையைப் பாதிக்காமல் ஒப்புதலைத் திரும்பப் பெறலாம். ஒப்புதல் தேவைப்படும் பிராந்தியங்களில் பொருந்தும் ஒப்புதல் தேவைகள் பூர்த்தி செய்யப்பட வேண்டும். விளம்பர ஒப்புதலுக்கும் பகுப்பாய்வு/கண்டறிதல் செயலாக்கத்துக்கும் தனித்தனி வரம்புகள் உள்ளன.

6. தக்கவைப்பு மற்றும் நீக்கம்

தகவல்தக்கவைப்பு மற்றும் நீக்கம்
சாதனத்தில் உள்ள கேம் சேமிப்புகள் மற்றும் அமைப்புகள்உங்கள் சாதனத்தில் இருக்கும் வரை வைக்கப்படும். ஆப்ஸின் முன்னேற்ற மீட்டமைப்பு, அந்த அம்சத்தில் அடங்கும் நிலை நிறைவு, நட்சத்திரம், பிற முன்னேற்றப் பதிவுகளை அழிக்கும்; அமைப்புகள், சில அதிகபட்ச மதிப்பெண் பதிவுகள், SDK தரவு இருக்கலாம். சாதனத் தரவை அகற்ற Android அமைப்புகளில் ஆப்ஸின் சேமிப்பகத்தை அழியுங்கள். நிறுவல் நீக்கம், காப்புப்பிரதித் தக்கவைப்பு, மீட்டமைப்பு ஆகியவை சாதன மற்றும் காப்புப்பிரதி அமைப்புகளைப் பொறுத்தவை.
Analytics தரவுAnalytics property-இன் தக்கவைப்பு அமைப்புகள் மற்றும் நீக்க நடைமுறைகளின்படி கையாளப்படும். நிலையான GA4 பொதுவாக 2 அல்லது 14 மாத பயனர்/நிகழ்வு நிலை அமைப்புகளை வழங்குகிறது; செயல்பாட்டின் அடிப்படையிலான புதுப்பித்தல் மற்றும் பிற அமைப்புகள் தக்கவைப்பைப் பாதிக்கலாம். இந்த வரம்புகள் எல்லா நிலையான ஒருங்கிணைந்த அறிக்கைகளுக்கும் ஒரே மாதிரி பொருந்தாது; ஒருங்கிணைந்த புள்ளிவிவரங்கள் நீண்ட காலம் இருக்கலாம்.
Crashlytics தரவுGoogle-இன் கூற்றுப்படி, செயலிழப்பு ஸ்டாக் ட்ரேஸ்களும் தொடர்புடைய அடையாளங்காட்டிகளும் 90 நாட்கள் வைக்கப்பட்ட பிறகு, நேரடி மற்றும் காப்புப்பிரதி அமைப்புகளிலிருந்து அகற்றும் செயல்முறை தொடங்கும். 90-ஆவது நாளில் நீக்கம் முடிந்துவிடும் என்று இதற்குப் பொருளில்லை.
விளம்பர மற்றும் ஒப்புதல் தரவுவிளம்பர வழங்கல், அளவீடு, மோசடித் தடுப்பு, தேர்வுகளை மதித்தல் ஆகியவற்றுக்குத் தேவையான காலத்துக்கு, Google மற்றும் தொடர்புடைய வழங்குநர்களின் தக்கவைப்பு/நீக்கக் கொள்கைகளின்படி கையாளப்படும். சாதனத்தில் உள்ள ஒப்புதல் அமைப்புகளுக்கும் வழங்குநர்களின் பதிவுகளுக்கும் தக்கவைப்புக் காலம் வேறுபடலாம்.
ஆதரவு மின்னஞ்சல்கள்கேள்வியும் தேவையான பின்தொடர்தலும் முடியும் வரை வைக்கப்பட்டு, பின்னர் நீக்கப்படும். சட்டப்படி தக்கவைக்க வேண்டியிருந்தால், தேவையான தகவல் மட்டும் பொருந்தும் சட்டக் காலத்துக்கு வைக்கப்படும்.
Google Play Games காப்புப்பிரதி மற்றும் சேவைத் தரவுபதிவுகள் உங்கள் Google கணக்கின் Saved Games-இல் சேமிக்கப்பட்டு, Google-இன் தக்கவைப்பு மற்றும் நீக்க நடைமுறைகளைப் பின்பற்றும். உள்நுழைந்த கணக்கை Android-இன் Google அமைப்புகளில் நிர்வகிக்கலாம்; இந்த கேமின் தரவை உங்கள் Play Games சுயவிவரம் அல்லது Google கணக்கின் கேம் தரவுக் கட்டுப்பாடுகள் மூலம் நீக்கலாம். நிறுவல் நீக்கமோ சாதன முன்னேற்ற மீட்டமைப்போ கிளவுட் நகலை நீக்காது; இணைப்பில் இருக்கும்போது பதிவுகள் மீண்டும் ஒன்றிணைக்கப்படலாம்.

ஆப்ஸ் தரவை அழித்தாலோ நிறுவல் நீக்கினாலோ Google-க்கு ஏற்கெனவே அனுப்பப்பட்ட தகவல் உடனடியாக நீக்கப்படாது. ஏற்கெனவே அனுப்பப்பட்ட தகவல் தொடர்பான உரிமைகளைப் பயன்படுத்த எங்களைத் தொடர்புகொள்ளுங்கள் அல்லது தொடர்புடைய Google தனியுரிமைக் கட்டுப்பாடுகளைப் பயன்படுத்துங்கள்.

7. சர்வதேசச் செயலாக்கம் மற்றும் பரிமாற்றம்

Google சேவைகளைப் பயன்படுத்துவதில், அமெரிக்கா மற்றும் Google மற்றும் அதன் தொடர்புடைய வழங்குநர்கள் வசதிகளை இயக்கும் பிற நாடுகள் உட்பட, உங்கள் நாட்டுக்கு வெளியே சேமிப்பும் செயலாக்கமும் நடக்கலாம். பெறுநர்களில் Google LLC மற்றும் தொடர்புடைய சேவை விதிமுறைகள் மற்றும் கொள்கைகளில் குறிப்பிடப்பட்ட துணை நிறுவனங்கள்/செயலாக்குநர்கள் அடங்குவர். செயலாக்க இடங்கள் Google-இன் தரவுச் செயலாக்க விதிமுறைகள் மற்றும் வசதித் தகவலைப் பொறுத்தவை.

தகவல்களும் நோக்கங்களும் தானியங்கிச் சேகரிப்பு மற்றும் வழங்குநர் பிரிவுகளில் விவரிக்கப்பட்டவை: விளம்பரம், பகுப்பாய்வு, செயலிழப்புக் கண்டறிதல், மின்னஞ்சல் ஆதரவு. SDK-கள் பயன்படுத்தப்படும்போது நெட்வொர்க் வழியாகப் பரிமாற்றம் நடக்கும். தக்கவைப்பு, தக்கவைப்புப் பிரிவு மற்றும் தொடர்புடைய வழங்குநர்களின் கொள்கைகளைப் பின்பற்றும். Google-இன் தனியுரிமைக் கொள்கையில் அதன் தனியுரிமைத் தொடர்பு வழிகள் உள்ளன.

சட்டப்படி தேவைப்படும் இடங்களில், ஒப்புதல் அல்லது ஒப்பந்தப் பாதுகாப்புகள் போன்ற பொருத்தமான பரிமாற்ற அடிப்படை பொருந்த வேண்டும். பரிமாற்றங்கள் அல்லது ஆட்சேபனைகள் குறித்து எங்கள் தனியுரிமை மின்னஞ்சலைத் தொடர்புகொள்ளுங்கள். விளம்பரத் தேர்வுகளைத் தொடர்புடைய செய்தி மற்றும் ஆப்ஸ் அமைப்புகள் மூலம் நிர்வகியுங்கள். வயதுவந்தோர் விருப்பத்தேர்வான பகுப்பாய்வையும் செயலிழப்பு அறிக்கையையும் அமைப்புகளில் நிறுத்தலாம்; பாதுகாக்கப்பட்ட பயனர்களுக்கு இந்தப் பகுப்பாய்வு/செயலிழப்புச் சேகரிப்பு பயன்படுத்தப்படுவதில்லை.

8. உங்கள் உரிமைகள் மற்றும் பிரதிநிதிகள்

பொருந்தும் சட்டத்தைப் பொறுத்து, அணுகல் அல்லது நகல், திருத்தம், நீக்கம், கட்டுப்பாடு, ஆட்சேபனை, ஒப்புதல் திரும்பப் பெறுதல், தரவுப் பெயர்வுத்திறன், அல்லது இலக்கு விளம்பரம் தொடர்பான தேர்வுகளைக் கோரலாம். சட்டம் அனுமதிக்கும் இடங்களில் பெற்றோர், பாதுகாவலர் அல்லது பிற அங்கீகரிக்கப்பட்ட பிரதிநிதி செயல்படலாம்.

எங்களுக்குச் சொந்த உறுப்பினர் கணக்குகளோ, நிறுவல் அடையாளங்காட்டிகளை உண்மைப் பெயர்கள் அல்லது மின்னஞ்சல் முகவரிகளுடன் இணைக்கும் பட்டியலோ இல்லை. விருப்பத்தேர்வான Play Games கணக்கு இணைப்புக்கும் நீக்கத்துக்கும் Google கட்டுப்பாடுகளை வழங்குகிறது. மின்னஞ்சல் முகவரி மட்டுமே ஒரு குறிப்பிட்ட நிறுவலின் SDK பதிவுகளை அடையாளம் காணப் போதுமானதாக இருக்காது. நியாயமாக முடிந்த இடங்களில் தொடர்புடைய பதிவுகளைக் கண்டறிய உதவி, வழங்குநர் கட்டுப்பாடுகளை விளக்குவோம். கோரிக்கையைக் கையாளத் தேவையான தகவலை மட்டுமே கேட்போம்; தேவையற்ற அரசு அடையாள எண்களையோ முக்கியமான தகவலையோ அனுப்ப வேண்டாம்.

9. குழந்தைகள் மற்றும் சிறார்கள்

இந்த ஆப்ஸ் எல்லா வயதினருக்குமானது. 18 வயதுக்குட்பட்ட பயனர்களுக்கும் பிறந்த தேதியை உள்ளிடாதவர்களுக்கும் கூடுதல் கவனமான பாதுகாப்புகள் பயன்படுத்தப்படும். பிறந்த தேதி சாதனத்தில் வயதைத் தீர்மானிக்க மட்டுமே பயன்படும்; சேமிக்கப்படுவதில்லை, அனுப்பப்படுவதில்லை. எல்லா கேம்களும் எல்லா வயதினருக்கும் கிடைக்கும். வயதுவந்தோர் வயது முன்கூட்டியே தேர்ந்தெடுக்கப்படுவதில்லை; கேம் பலன்களுக்கான நிபந்தனையாகவும் காட்டப்படுவதில்லை.

பாதுகாக்கப்பட்ட பயனர்களுக்கு Firebase பகுப்பாய்வு அல்லது செயலிழப்பு அறிக்கை SDK-கள் தொடங்குவதில்லை. விளம்பரங்கள் Families சுய-சான்றளிக்கப்பட்ட பதிப்பு வரம்பிலுள்ள Google Mobile Ads-ஐப் பயன்படுத்துகின்றன; G மதிப்பீடு, தனிப்பயனாக்கம் இல்லாமை, குழந்தைகளுக்கான விளம்பர அமைப்பு ஆகியவை பொருந்தும். பாதுகாக்கப்பட்ட பயனர்களின் Android விளம்பர ID அனுப்பப்படுவதில்லை. குழந்தைகளுக்கான விளம்பர அமைப்பு, சூழல் சார்ந்த விளம்பரங்களை வழங்கவும் பாதுகாப்பைப் பேணவும் தேவையான எல்லா நெட்வொர்க் செயலாக்கத்தையும் நீக்குவதில்லை; மேலே உள்ள SDK தகவலைப் பாருங்கள்.

குழந்தைகளின் தகவல், பெற்றோர் அனுமதி, கூடுதல் பாதுகாப்புகள் தொடர்பான பொருந்தும் விதிகள் தொடர்ந்து பொருந்தும். குழந்தையின் தகவல் அல்லது தேவையான அனுமதியின்றிச் செயலாக்கம் குறித்துக் கவலைப்படும் பெற்றோர் அல்லது பாதுகாவலர்கள் எங்கள் தனியுரிமை மின்னஞ்சலைத் தொடர்புகொள்ளலாம். நியாயமாக முடிந்த இடங்களில் விசாரித்து, தேவையான நீக்கம், கட்டுப்பாடு அல்லது பிற நடவடிக்கைகளை எடுப்போம்.

10. பாதுகாப்பு

சேவை நிர்வாகக் கணக்குகளுக்கும் தனிப்பட்ட தரவுக்குமான அணுகலைத் தேவையானதற்கு மட்டும் கட்டுப்படுத்துகிறோம்; வழங்குநர் பாதுகாப்பு அம்சங்கள், பரிமாற்றத்தின்போது குறியாக்கம் போன்ற பொருத்தமான பாதுகாப்புகளைப் பயன்படுத்துகிறோம். சாதனத்தில் உள்ள தகவல் இயக்க முறைமையின் ஆப்ஸ் சேமிப்பகப் பாதுகாப்புகளுக்கு உட்பட்டது. இனி தேவையில்லாத தகவல் தொடர்புடைய தக்கவைப்பு மற்றும் நீக்க நடைமுறைகளின்படி நீக்கப்படும் அல்லது அடையாளம் நீக்கப்படும்.

ஆதரவுக் கோரிக்கையைத் தீர்க்கத் தேவையில்லாத கடவுச்சொற்கள், அரசு அடையாள எண்கள், கட்டண விவரங்கள் அல்லது பிற முக்கியமான தகவல்களைச் சேர்க்க வேண்டாம்.

11. இந்தக் கொள்கை இணையதளம்

இந்தப் பக்கத்தில் டெவலப்பர் நிறுவிய விளம்பரங்கள், பார்வையாளர் பகுப்பாய்வு SDK-கள், கண்காணிப்பு ஸ்கிரிப்ட்கள் அல்லது கண்காணிப்பு குக்கீகள் இல்லை. இது GitHub Pages-இல் வழங்கப்படுகிறது. GitHub தனது சொந்தத் தனியுரிமை அறிக்கையின்படி, பாதுகாப்பு மற்றும் தொடர்புடைய நோக்கங்களுக்காகப் பார்வையாளர் IP முகவரிகளையும் பிற இணைப்புத் தகவலையும் கையாளலாம். வெளிப்புறக் கொள்கை இணைப்பைத் திறந்தால் அந்த வழங்குநரின் இணையதளத்துக்கும் கொள்கைகளுக்கும் செல்வீர்கள்.

நிலை உள்ளடக்கப் புதுப்பிப்புகளுக்காக ஆப்ஸ் GitHub Pages-ஐச் சரிபார்த்து, மாற்றப்பட்ட கேம் தரவைப் பதிவிறக்கும். இந்தக் கோரிக்கைகளில் Play Games கணக்குத் தகவலோ தனிப்பட்ட விளையாட்டுப் பதிவுகளோ இல்லை. GitHub தனது சொந்தத் தனியுரிமை அறிக்கையின்படி, உள்ளடக்கத்தை வழங்கவும் பாதுகாக்கவும் IP முகவரிகளையும் பிற வழக்கமான இணைப்புத் தகவலையும் கையாளலாம்.
