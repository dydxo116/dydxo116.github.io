2. 端末に保存されるゲームデータなど

初回利用時に端末のメモリ上で生年月日を確認し、利用者が保護対象または成人のどちらに該当するかを判定します。生年月日と数値で表した年齢は保存せず、サーバーにも送信しません。大まかな利用者区分と、任意の分析・不具合報告への同意だけを、Androidバックアップの対象外となる端末内領域に保存します。入力をスキップした場合や設定の欠落・破損がある場合は、保護対象として扱います。

ステージの進行、星、ハイスコア、中断したゲーム、最近遊んだゲーム、音・振動・言語の設定、チュートリアルの状態、広告間隔、同意の選択は、アプリまたは SDK の端末内ストレージに保存されます。ゲームアカウントや、セーブファイルをアップロード・同期する独自のサーバーは提供していません。

Google Play Games のバックアップは広告の年齢保護とは別の任意機能です。連携の説明を読み、連携を選択した場合にのみ SDK を開始します。Google のログインと保存サービスが利用を許可した場合、ステージ・星・最高記録を Google Saved Games に保存し、端末間で統合します。生年月日・広告の選択・設定・途中の盤面は含めません。Google はサービス提供と改善のため、Play Games プロフィールと SDK 自体の利用・診断情報も処理します。本アプリは友だち一覧・メール・ソーシャル機能を要求せず、Play Games 情報を広告に利用しません。お子様の管理対象アカウントは Google の保護者承認とサービスの対応状況に従い、すべてのアカウントで保存できるとは限りません。未連携や利用拒否の場合も、端末に保存して全ゲームを遊べます。広告と Firebase の保護設定は維持されます。連携の選択は Android バックアップ対象外の端末領域に保存します。既存利用者にも一度説明を表示し、あとからアプリ設定で連携できます。

登録やログインは不要です。氏名、電話番号、住所、連絡先、写真、マイクの録音、正確な GPS 位置情報の提出を求めたり、それらを収集する機能を設けたりしていません。メールでお問い合わせいただくと、送信元のメールアドレスと本文を受け取ります。

Android のバックアップと復元が有効な場合、端末や Google アカウントの設定に応じ、一部のアプリデータが OS 提供者によってバックアップされ、再インストール時に復元されることがあります。これは開発者が運営するゲームアカウントとは別の仕組みです。Android のバックアップ設定で管理できます。

3. 自動的に処理される情報と目的

配信されるアプリには、以下の Google SDK が含まれます。アプリの利用時やネットワーク接続時に情報を自動的に処理することがあります。具体的な範囲は SDK のバージョン、端末・地域の設定、同意の状態、Google サービスの設定により異なります。

すべての年齢で、アップデートの確認には独立したFirebase Remote ConfigとFirebase Installationsを使用する場合があります。設定の配信と機能の提供のため、更新専用のインストール識別子・認証トークン、アプリのバージョン、言語、OS、接続時のIPアドレスが処理されます。任意の利用分析・障害報告とは別であり、更新確認によってAnalytics・Crashlytics・広告IDの収集を開始することはありません。広告・分析用のユーザープロパティ、実験、パーソナライズは使用しません。

氏名、メールアドレス、電話番号を Analytics のユーザー ID に設定したり、セーブファイルを分析イベントとして送信したりすることはありません。ただし、端末・アプリの識別子も、実名でなくても適用法令上の個人情報に該当する場合があります。

年齢の判断前、または 18 歳未満・年齢不明の保護対象利用者に対して、Firebase Core、Analytics、Crashlytics を起動しません。成人は利用状況の分析と不具合報告を明示的に選択でき、設定から両方をまとめて無効にできます。

4. Google などのサービス提供者

上記の情報は、広告、分析、不具合報告のために、Google LLC および各サービスの規約で示される Google 関連会社へ送信され、処理されることがあります。サービスと規約により、Google は当方の処理委託先または独立した管理者として情報を扱います。

地域、利用者の選択、広告設定によっては、Google の広告技術提供者が広告リクエストや測定の情報を処理することがあります。同意メッセージが表示される場合は、対象の提供者と選択肢について、メッセージおよび Google の関連情報をご確認ください。

サポートメールは Gmail（Google）で受信・保管します。メール提供者は、送信元アドレス、本文、および任意に送付された添付ファイルを処理することがあります。お問い合わせの解決に必要な情報だけをお送りください。

当方は個人情報を販売する別事業を行っていません。ただし、広告に伴う情報の提供は、一部の法律では「共有」やターゲティング広告の処理に該当することがあります。以下の選択肢をご確認ください。法的義務や適法な要請に従う場合、またはご本人のご依頼に対応する場合にも、必要最小限の情報を提供することがあります。

5. 広告の選択、同意、処理の根拠

端末内で年齢を判断するか、入力をスキップするまで、広告プライバシー関連や広告のリクエストを行いません。成人向けの任意の分析・不具合報告への同意は初期状態では未選択です。同意しなくてもすべてのゲームを利用できます。設定で利用状況の分析と不具合報告を無効にすると、以後の収集を止め、端末の未送信クラッシュレポートを削除します。送信済みの記録が自動的に消えるわけではありません。

広告 SDK は Google UMP が広告リクエストを許可した後に広告を要求します。地域や Google の要件に応じ、広告に関する通知や同意メッセージが表示されることがあります。プライバシーオプションが必要な場合は、アプリの設定に表示される広告のプライバシーオプションから選択を確認・変更できます。この項目は UMP が必要と判断したときに表示されます。

アプリは G レーティングの、パーソナライズされていない広告を要求します。18 歳未満または年齢不明の保護対象には、Google の子ども向けの取り扱いと UMP の同意年齢未満の設定を適用します。非パーソナライズ広告や制限付き広告でも、IP・おおよその位置、許可された識別子、操作、診断情報を処理することがあります。広告への同意を拒否したり広告の読み込みに失敗したりしても、ゲームは遊べます。

広告 ID の削除など、利用可能な選択肢は Android のプライバシー・広告設定で管理できます。名称や項目は端末によって異なります。Google アカウントの広告管理は Google サービスの範囲で別途適用されます。

適用法令に応じ、サービスの提供、信頼性・安全性・改善に関する正当な利益、法的義務、または必要な場合の同意を根拠に処理します。同意に基づく処理では、撤回前の処理の適法性に影響を与えずに同意を撤回できます。同意が必要な地域では、その要件を満たす必要があります。広告の同意と分析・診断の処理は、適用範囲が別です。

6. 保存期間と削除

情報保存期間と削除
端末内のセーブデータと設定端末に残っている間は保存されます。アプリの進行状況リセットでは、その機能の対象となるステージのクリア、星、その他の進行記録を削除します。設定、一部のハイスコア、SDK データは残る場合があります。端末内のデータを削除するには、Android 設定でアプリのストレージを消去してください。アンインストール、バックアップの保持、復元は端末とバックアップの設定によって異なります。
Analytics データAnalytics プロパティの保存設定と削除手続きに従います。標準の GA4 では通常、ユーザー・イベント単位で 2 か月または 14 か月の設定があり、利用に応じた期間の更新などの設定も影響します。すべての標準集計レポートに同じ制限が適用されるわけではなく、集計統計はより長く残ることがあります。
Crashlytics データGoogle の説明では、クラッシュのスタックトレースと関連識別子は 90 日間保存され、その後に稼働中のシステムとバックアップからの削除手続きが始まります。90 日目に削除が完了するという意味ではありません。
広告と同意のデータ広告の配信・測定、不正防止、選択の尊重に必要な期間、Google および関連提供者の保存・削除方針に従って処理されます。端末内の同意設定と提供者側の記録では、保存期間が異なる場合があります。
サポートメールお問い合わせと必要な事後対応が完了するまで保管し、その後削除します。法令による保存義務がある場合は、必要な情報だけを法定期間保存します。
Google Play Games のバックアップとサービス情報記録は Google アカウントの Saved Games に保管され、Google の保管・削除手続きに従います。Android の Google 設定でログイン先を管理し、Play Games プロフィールや Google アカウントのゲームデータ管理から本ゲームのデータを削除できます。アンインストールや端末側の初期化だけではクラウドの記録は削除されず、連携中は再び統合されることがあります。

アプリデータの消去やアンインストールだけでは、Google に送信済みの情報はすぐに削除されません。送信済み情報について権利を行使するには、当方へのお問い合わせや Google の該当するプライバシー管理機能をご利用ください。

7. 国外での処理と移転

Google サービスの利用により、米国を含む、Google や関連提供者が設備を持つお住まいの国以外の国で情報が保存・処理されることがあります。移転先には、各サービスの規約・方針に示される Google LLC、関連会社、処理委託先が含まれます。処理場所は Google のデータ処理条件と施設情報によります。

対象情報と目的は、自動収集と提供者の各節に記載した、広告、分析、不具合診断、メールサポートに関するものです。SDK 利用中にネットワークを通じて移転します。保存期間は保存に関する節と各提供者の方針に従います。Google のプライバシーポリシーに同社の問い合わせ窓口が記載されています。

法令上必要な場合は、同意や契約上の保護措置など、適切な移転の根拠が必要です。移転や異議については当方の個人情報窓口へご連絡ください。広告の選択は該当するメッセージとアプリ設定で管理できます。成人は設定から任意の分析・不具合報告も停止できます。保護対象にはこれらの分析・不具合収集を行いません。

9. 子どもと未成年者

本アプリは全年齢向けです。18 歳未満と生年月日を入力しない利用者に対し、保守的な保護措置を適用します。生年月日は端末内の年齢判断にのみ使用し、保存・送信しません。どの年齢でもすべてのゲームを利用できます。成人の年齢をあらかじめ選んだり、ゲーム内の特典を得る条件として提示したりしません。

保護対象のユーザーでは、Firebase の分析・不具合報告 SDK を起動しません。広告には Families の自己認証対象バージョン範囲の Google Mobile Ads を使用し、G レーティング、非パーソナライズ、子ども向けの設定を適用します。保護対象ユーザーの Android 広告 ID は送信しません。子ども向けの設定でも、コンテキスト広告の配信や安全確保に必要な通信処理がすべてなくなるわけではありません。上記の SDK 情報をご確認ください。

子どもの情報、保護者の許可、追加的な保護に関する法令は引き続き適用されます。子どもの情報や必要な許可なしでの処理について懸念がある保護者は、当方の個人情報窓口へご連絡ください。合理的に可能な範囲で調査し、削除、制限などの必要な措置を講じます。

10. 安全管理

サービス管理アカウントと個人情報へのアクセスは必要な範囲に限定し、提供者のセキュリティ機能や通信の暗号化など、適切な保護措置を用います。端末内の情報は OS のアプリ領域の保護を受けます。不要になった情報は、該当する保存・削除手続きに従って削除または非識別化します。

サポート依頼の解決に不要なパスワード、公的識別番号、決済情報、その他の機微な情報は記載しないでください。
