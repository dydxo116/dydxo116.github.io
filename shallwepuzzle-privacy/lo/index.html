Google Analytics for Firebaseສະເພາະຜູ້ໃຫຍ່ທີ່ເລືອກຍິນຍອມ: ຕົວລະບຸ app instance/ການຕິດຕັ້ງ, ລຸ້ນອຸປະກອນ, ລະບົບປະຕິບັດການ, ເວີຊັນແອັບ ແລະ ພາສາ, ເຫດການເຊສຊັນ/ໜ້າຈໍ ແລະ ຂໍ້ມູນ IP/ພາກພື້ນທົ່ວໄປທີ່ SDK ປະມວນຜົນ. ການເກັບ advertising ID ຂອງ Analytics, ad storage, ad user data ແລະ ສັນຍານ ad personalization ຖືກປິດໄວ້. Analytics ຍັງລວມເຖິງກິດຈະກຳເກມ ແລະ ດ່ານ, ຜົນການຫຼິ້ນ ແລະ ການລອງໃໝ່, ການສະແດງໂຄສະນາ ແລະ ການປ່ຽນການຕັ້ງຄ່າ.ເຂົ້າໃຈການນຳໃຊ້, ການໃຊ້ຄຸນສົມບັດ ແລະ ແນວໂນ້ມຄວາມສະຖຽນ ເພື່ອປັບປຸງບໍລິການ
Firebase Crashlytics ແລະ ບໍລິການ Firebase installationສະເພາະຜູ້ໃຫຍ່ທີ່ເລືອກຍິນຍອມ: ຕົວລະບຸການຕິດຕັ້ງ/ເຊສຊັນ, ເວລາຂັດຂ້ອງ/ຂໍ້ຜິດພາດ ແລະ stack trace, ຂໍ້ຄວາມຂໍ້ຜິດພາດ, ເວີຊັນແອັບ, ລະບົບປະຕິບັດການ, ລຸ້ນອຸປະກອນ, ໜ່ວຍຄວາມຈຳ ແລະ ຂໍ້ມູນວິນິດໄສທີ່ກ່ຽວຂ້ອງ, ແລະ ເຫດການຂອງແອັບກ່ອນການຂັດຂ້ອງທີ່ເຊື່ອມໂຍງກັນກວດພົບ ແລະ ສືບສວນຂໍ້ຜິດພາດ, ວັດຈຳນວນການຕິດຕັ້ງທີ່ໄດ້ຮັບຜົນກະທົບ ແລະ ປັບປຸງຄວາມໜ້າເຊື່ອຖື

Google Play In-App Updatesເມຕາເດຕາຂອງແອັບ ແລະ ອຸປະກອນ, ເວີຊັນແອັບທີ່ຕິດຕັ້ງ, ສະຖານະການອັບເດດ ແລະ ຂໍ້ມູນຂໍ້ຜິດພາດກວດວ່າມີອັບເດດຜ່ານ Google Play ຫຼື ບໍ່, ດາວໂຫຼດ, ຕິດຕັ້ງ ແລະ ເປີດແອັບຄືນໃໝ່

4. Google ແລະ ຜູ້ໃຫ້ບໍລິການອື່ນ

ຂໍ້ມູນທີ່ອະທິບາຍຂ້າງເທິງອາດຖືກສົ່ງໄປ ແລະ ປະມວນຜົນໂດຍ Google LLC ແລະ ບໍລິສັດໃນເຄືອ Google ທີ່ລະບຸໄວ້ໃນເງື່ອນໄຂບໍລິການທີ່ກ່ຽວຂ້ອງ ເພື່ອໂຄສະນາ, ການວິເຄາະ ແລະ ລາຍງານການຂັດຂ້ອງ. ຂຶ້ນກັບພາກພື້ນ, ການເລືອກ ແລະ ການຕັ້ງຄ່າໂຄສະນາຂອງທ່ານ, ຜູ້ໃຫ້ບໍລິການເທັກໂນໂລຢີໂຄສະນາຂອງ Google ອາດປະມວນຜົນຂໍ້ມູນຄຳຮ້ອງຂໍໂຄສະນາ ແລະ ການວັດຜົນ. ຖ້າມີຂໍ້ຄວາມຂໍຄວາມຍິນຍອມສະແດງ ໃຫ້ເບິ່ງຂໍ້ຄວາມນັ້ນ ແລະ ຂໍ້ມູນທີ່ກ່ຽວຂ້ອງຂອງ Google ເພື່ອຮູ້ຜູ້ໃຫ້ບໍລິການ ແລະ ທາງເລືອກທີ່ກ່ຽວຂ້ອງ.

ພວກເຮົາຮັບ ແລະ ເກັບອີເມວຊ່ວຍເຫຼືອຜ່ານ Gmail (Google). ຜູ້ໃຫ້ບໍລິການອີເມວອາດປະມວນຜົນທີ່ຢູ່ຜູ້ສົ່ງ, ຂໍ້ຄວາມ ແລະ ໄຟລ໌ແນບທີ່ທ່ານເລືອກສົ່ງ. ກະລຸນາສົ່ງສະເພາະຂໍ້ມູນທີ່ຈຳເປັນເພື່ອແກ້ໄຂຄຳຖາມຂອງທ່ານ.

ພວກເຮົາບໍ່ໄດ້ດຳເນີນທຸລະກິດຂາຍຂໍ້ມູນສ່ວນບຸກຄົນແຍກຕ່າງຫາກ. ການເປີດເຜີຍຂໍ້ມູນເພື່ອໂຄສະນາອາດຖືວ່າເປັນ 'ການແບ່ງປັນ' ຫຼື ການປະມວນຜົນເພື່ອໂຄສະນາແບບເຈາະຈົງຕາມກົດໝາຍບາງສະບັບ; ເບິ່ງທາງເລືອກຂ້າງລຸ່ມ. ພວກເຮົາອາດເປີດເຜີຍຂໍ້ມູນຢ່າງຈຳກັດ ເມື່ອຈຳເປັນເພື່ອປະຕິບັດຕາມພັນທະທາງກົດໝາຍ ຫຼື ຄຳຮ້ອງຂໍທີ່ຖືກຕ້ອງຕາມກົດໝາຍ ຫຼື ເພື່ອດຳເນີນການຕາມຄຳຮ້ອງຂໍຂອງທ່ານ.

5. ທາງເລືອກດ້ານໂຄສະນາ, ຄວາມຍິນຍອມ ແລະ ພື້ນຖານການປະມວນຜົນ

ແອັບຈະລໍໃຫ້ມີການຕັດສິນອາຍຸໃນອຸປະກອນ ຫຼື ການເລືອກຂ້າມ ກ່ອນຈະສົ່ງຄຳຮ້ອງຂໍດ້ານຄວາມເປັນສ່ວນຕົວຂອງໂຄສະນາ ຫຼື ຄຳຮ້ອງຂໍໂຄສະນາ. ຄວາມຍິນຍອມຕໍ່ການວິເຄາະ/ລາຍງານການຂັດຂ້ອງແບບບໍ່ບັງຄັບສຳລັບຜູ້ໃຫຍ່ ບໍ່ໄດ້ຖືກເລືອກໄວ້ລ່ວງໜ້າ ແລະ ການປະຕິເສດບໍ່ຈຳກັດເກມໃດເລີຍ. ການປິດ 'ການວິເຄາະການນຳໃຊ້ ແລະ ລາຍງານການຂັດຂ້ອງ' ໃນການຕັ້ງຄ່າ ຈະຢຸດການເກັບຂໍ້ມູນຕໍ່ໄປ ແລະ ລຶບລາຍງານການຂັດຂ້ອງທີ່ຍັງບໍ່ໄດ້ສົ່ງໃນອຸປະກອນ. ແຕ່ຈະບໍ່ລຶບບັນທຶກທີ່ສົ່ງໄປແລ້ວໂດຍອັດຕະໂນມັດ.

SDK ໂຄສະນາຈະຮ້ອງຂໍໂຄສະນາຫຼັງຈາກ Google UMP ແຈ້ງວ່າອະນຸຍາດໃຫ້ຮ້ອງຂໍໂຄສະນາໄດ້. ແຈ້ງການໂຄສະນາ ຫຼື ຂໍ້ຄວາມຂໍຄວາມຍິນຍອມອາດປາກົດ ຂຶ້ນກັບພາກພື້ນຂອງທ່ານ ແລະ ຂໍ້ກຳນົດຂອງ Google. ເມື່ອຈຳເປັນຕ້ອງມີທາງເລືອກຄວາມເປັນສ່ວນຕົວ ທ່ານສາມາດເບິ່ງຄືນ ຫຼື ປ່ຽນການເລືອກໄດ້ທີ່ລາຍການທາງເລືອກຄວາມເປັນສ່ວນຕົວດ້ານໂຄສະນາໃນການຕັ້ງຄ່າແອັບ. ລາຍການນີ້ຈະສະແດງເມື່ອ UMP ກຳນົດວ່າຈຳເປັນເທົ່ານັ້ນ.

ແອັບຮ້ອງຂໍໂຄສະນາລະດັບ G ທີ່ບໍ່ປັບຕາມບຸກຄົນ. ສຳລັບຜູ້ໃຊ້ທີ່ຕ້ອງປົກປ້ອງ ເຊິ່ງອາຍຸຕ່ຳກວ່າ 18 ປີ ຫຼື ບໍ່ຮູ້ອາຍຸ, ແອັບໃຊ້ການຕັ້ງຄ່າອາຍຸເດັກຂອງ Google ແລະ ການຕັ້ງຄ່າຕ່ຳກວ່າອາຍຸທີ່ໃຫ້ຄວາມຍິນຍອມໄດ້ຂອງ UMP. ໂຄສະນາທີ່ບໍ່ປັບຕາມບຸກຄົນ ຫຼື ແບບຈຳກັດ ຍັງອາດປະມວນຜົນ IP/ຕຳແໜ່ງທົ່ວໄປ, ຕົວລະບຸທີ່ໄດ້ຮັບອະນຸຍາດ, ການໂຕ້ຕອບ ແລະ ຂໍ້ມູນວິນິດໄສ. ການປະຕິເສດຄວາມຍິນຍອມດ້ານໂຄສະນາ ຫຼື ການໂຫຼດໂຄສະນາບໍ່ສຳເລັດ ບໍ່ໄດ້ກີດຂວາງການຫຼິ້ນ.

ທ່ານສາມາດຈັດການທາງເລືອກ ID ໂຄສະນາທີ່ມີ ເຊັ່ນ ການລຶບ ID ໄດ້ໃນການຕັ້ງຄ່າຄວາມເປັນສ່ວນຕົວ/ໂຄສະນາຂອງ Android. ຊື່ ແລະ ຕົວເລືອກແຕກຕ່າງກັນຕາມອຸປະກອນ. ການຄວບຄຸມໂຄສະນາຂອງບັນຊີ Google ມີຜົນແຍກຕ່າງຫາກພາຍໃນຂອບເຂດບໍລິການຂອງ Google.

ຂຶ້ນກັບກົດໝາຍທີ່ກ່ຽວຂ້ອງ, ການປະມວນຜົນອີງໃສ່ການໃຫ້ບໍລິການ, ຜົນປະໂຫຍດອັນຊອບທຳດ້ານຄວາມໜ້າເຊື່ອຖື ຄວາມປອດໄພ ແລະ ການປັບປຸງບໍລິການ, ພັນທະທາງກົດໝາຍ ຫຼື ຄວາມຍິນຍອມໃນກໍລະນີທີ່ຈຳເປັນ. ສຳລັບການປະມວນຜົນທີ່ອີງໃສ່ຄວາມຍິນຍອມ ທ່ານສາມາດຖອນຄວາມຍິນຍອມໄດ້ ໂດຍບໍ່ກະທົບຕໍ່ຄວາມຖືກຕ້ອງຕາມກົດໝາຍຂອງການປະມວນຜົນກ່ອນໜ້ານັ້ນ. ໃນພາກພື້ນທີ່ຕ້ອງການຄວາມຍິນຍອມ ຕ້ອງປະຕິບັດຕາມຂໍ້ກຳນົດທີ່ກ່ຽວຂ້ອງ. ຄວາມຍິນຍອມດ້ານໂຄສະນາ ແລະ ການປະມວນຜົນເພື່ອວິເຄາະ/ວິນິດໄສ ມີຂອບເຂດແຍກກັນ.

6. ການເກັບຮັກສາ ແລະ ການລຶບ

ຂໍ້ມູນການເກັບຮັກສາ ແລະ ການລຶບ
ຂໍ້ມູນເກມ ແລະ ການຕັ້ງຄ່າໃນອຸປະກອນເກັບໄວ້ຕາບໃດທີ່ຍັງຢູ່ໃນອຸປະກອນຂອງທ່ານ. ການຣີເຊັດຄວາມຄືບໜ້າໃນແອັບ ຈະລຶບບັນທຶກການຜ່ານດ່ານ, ດາວ ແລະ ຄວາມຄືບໜ້າອື່ນທີ່ຄຸນສົມບັດນັ້ນຄອບຄຸມ; ການຕັ້ງຄ່າ, ບັນທຶກຄະແນນສູງສຸດບາງສ່ວນ ແລະ ຂໍ້ມູນ SDK ອາດຍັງເຫຼືອຢູ່. ເພື່ອລຶບຂໍ້ມູນໃນອຸປະກອນ ໃຫ້ລ້າງບ່ອນເກັບຂໍ້ມູນຂອງແອັບໃນການຕັ້ງຄ່າ Android. ການຖອນການຕິດຕັ້ງ, ການເກັບຂໍ້ມູນສຳຮອງ ແລະ ການກູ້ຄືນ ຂຶ້ນກັບການຕັ້ງຄ່າອຸປະກອນ ແລະ ການສຳຮອງຂໍ້ມູນ.
ຂໍ້ມູນ Analyticsຈັດການຕາມການຕັ້ງຄ່າການເກັບຮັກສາ ແລະ ຂັ້ນຕອນການລຶບຂອງ Analytics property. ໂດຍທົ່ວໄປ GA4 ມາດຕະຖານມີການຕັ້ງຄ່າລະດັບຜູ້ໃຊ້/ເຫດການ 2 ເດືອນ ຫຼື 14 ເດືອນ; ການຕໍ່ອາຍຸຕາມກິດຈະກຳ ແລະ ການຕັ້ງຄ່າອື່ນອາດມີຜົນຕໍ່ໄລຍະເກັບຮັກສາ. ຂີດຈຳກັດເຫຼົ່ານີ້ບໍ່ໄດ້ໃຊ້ແບບດຽວກັນກັບລາຍງານລວມມາດຕະຖານທັງໝົດ ແລະ ສະຖິຕິລວມອາດຢູ່ໄດ້ດົນກວ່າ.

ກົດລະບຽບທີ່ກ່ຽວຂ້ອງກັບຂໍ້ມູນຂອງເດັກ, ການອະນຸຍາດຈາກພໍ່ແມ່ ແລະ ການປົກປ້ອງເພີ່ມເຕີມ ຍັງມີຜົນບັງຄັບໃຊ້. ພໍ່ແມ່ ຫຼື ຜູ້ປົກຄອງທີ່ກັງວົນກ່ຽວກັບຂໍ້ມູນຂອງເດັກ ຫຼື ການປະມວນຜົນໂດຍບໍ່ມີການອະນຸຍາດທີ່ຈຳເປັນ ສາມາດຕິດຕໍ່ອີເມວດ້ານຄວາມເປັນສ່ວນຕົວຂອງພວກເຮົາໄດ້. ພວກເຮົາຈະກວດສອບເທົ່າທີ່ເຮັດໄດ້ ແລະ ດຳເນີນການລຶບ, ຈຳກັດ ຫຼື ມາດຕະການອື່ນທີ່ຈຳເປັນ.

10. ຄວາມປອດໄພ

ພວກເຮົາຈຳກັດການເຂົ້າເຖິງບັນຊີຜູ້ດູແລບໍລິການ ແລະ ຂໍ້ມູນສ່ວນບຸກຄົນເທົ່າທີ່ຈຳເປັນ ແລະ ໃຊ້ມາດຕະການປົກປ້ອງທີ່ເໝາະສົມ ເຊັ່ນ ຄຸນສົມບັດຄວາມປອດໄພຂອງຜູ້ໃຫ້ບໍລິການ ແລະ ການເຂົ້າລະຫັດລະຫວ່າງການສົ່ງ. ຂໍ້ມູນໃນອຸປະກອນຢູ່ພາຍໃຕ້ການປົກປ້ອງບ່ອນເກັບຂໍ້ມູນແອັບຂອງລະບົບປະຕິບັດການ. ຂໍ້ມູນທີ່ບໍ່ຈຳເປັນອີກຕໍ່ໄປຈະຖືກລຶບ ຫຼື ເຮັດໃຫ້ລະບຸຕົວຕົນບໍ່ໄດ້ ຕາມຂັ້ນຕອນການເກັບຮັກສາ ແລະ ການລຶບທີ່ກ່ຽວຂ້ອງ.

ຢ່າໃສ່ລະຫັດຜ່ານ, ເລກປະຈຳຕົວທາງການ, ລາຍລະອຽດການຊຳລະເງິນ ຫຼື ຂໍ້ມູນອ່ອນໄຫວອື່ນທີ່ບໍ່ຈຳເປັນຕໍ່ການແກ້ໄຂຄຳຮ້ອງຂໍຄວາມຊ່ວຍເຫຼືອ.

11. ເວັບໄຊນະໂຍບາຍນີ້

ໜ້ານີ້ບໍ່ມີໂຄສະນາ, SDK ວິເຄາະຜູ້ເຂົ້າຊົມ, ສະຄຣິບຕິດຕາມ ຫຼື ຄຸກກີ້ຕິດຕາມທີ່ຜູ້ພັດທະນາຕິດຕັ້ງ. ໜ້ານີ້ໂຮສຢູ່ GitHub Pages. GitHub ອາດປະມວນຜົນທີ່ຢູ່ IP ຂອງຜູ້ເຂົ້າຊົມ ແລະ ຂໍ້ມູນການເຊື່ອມຕໍ່ອື່ນ ເພື່ອຄວາມປອດໄພ ແລະ ຈຸດປະສົງທີ່ກ່ຽວຂ້ອງ ຕາມຖະແຫຼງການຄວາມເປັນສ່ວນຕົວຂອງ GitHub ເອງ. ເມື່ອເປີດລິ້ງນະໂຍບາຍພາຍນອກ ທ່ານຈະໄປທີ່ເວັບໄຊ ແລະ ນະໂຍບາຍຂອງຜູ້ໃຫ້ບໍລິການນັ້ນ.

ແອັບກວດ GitHub Pages ເພື່ອຫາອັບເດດເນື້ອຫາດ່ານ ແລະ ດາວໂຫຼດຂໍ້ມູນເກມທີ່ມີການປ່ຽນແປງ. ຄຳຮ້ອງຂໍເຫຼົ່ານີ້ບໍ່ມີຂໍ້ມູນບັນຊີ Play Games ຫຼື ບັນທຶກການຫຼິ້ນສ່ວນຕົວ. GitHub ອາດປະມວນຜົນທີ່ຢູ່ IP ແລະ ຂໍ້ມູນການເຊື່ອມຕໍ່ທົ່ວໄປອື່ນ ເພື່ອສົ່ງ ແລະ ຮັກສາຄວາມປອດໄພຂອງເນື້ອຫາ ຕາມຖະແຫຼງການຄວາມເປັນສ່ວນຕົວຂອງ GitHub ເອງ.
