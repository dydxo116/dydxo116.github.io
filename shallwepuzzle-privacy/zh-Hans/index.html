如有隐私权问题、申诉，或欲申请查阅、更正、删除、限制处理或撤回同意，请发送邮件至下方电子邮件地址。我们可能要求提供合理必要的信息，以核实请求并找出相关数据，并依适用法律的进程及期限回复。

2. 设备上的游戏存档与信息

首次使用时会在设备内存中检查出生日期，以判定用户属于受保护类别或成人类别。出生日期与实际年龄数字均不保存，也不发送至服务器。仅将大致用户类别，以及是否选择分析与崩溃报告，存于不纳入 Android 备份的设备空间。跳过输入、设置缺失或损坏时，均归入受保护类别。

关卡进度、星星、最高分、未完成及最近游玩的游戏、音效、震动、语言偏好、教学状态、广告间隔与同意选择，由应用程序或 SDK 保存在设备本机。我们不提供游戏账号，也没有用于上传或同步游戏存档的独立服务器。

Google Play 游戏备份是与广告年龄保护分开的可选功能。阅读连接说明并选择连接后，才会启动 SDK。Google 允许登录及访问保存服务时，关卡、星星与最佳记录会存入 Google Saved Games，并在设备间合并。此备份不含出生日期、广告选择、设置或未完成的棋盘。Google 也会处理游戏个人资料及 SDK 本身的使用与诊断信息，以提供及改进服务。本应用程序不要求好友名单、电子邮件或社交功能，也不将 Play 游戏数据用于广告。受监督的儿童账号须依 Google 的家长批准及服务支持情况使用，不保证每个账号都能保存。未连接或访问遭拒时，仍可在设备上保存并游玩所有游戏。广告与 Firebase 保护设置维持不变。连接选择存于不纳入 Android 备份的设备保存空间。现有用户也会看到一次说明，之后可在应用程序设置中连接。

本应用程序不要求注册或登录，不要求提供姓名、电话、地址、联系人、照片、麦克风录音或精确 GPS 位置，也未设置搜集这些信息的功能。如果您发送邮件给我们，我们会收到发件人的电子邮件地址与内容。

若激活 Android 备份与还原，操作系统提供商可能依设备及 Google 账号设置备份部分应用程序数据，并于重新安装后还原。这与开发者营运的游戏账号无关，您可在 Android 备份设置中管理。

3. 自动处理的信息与目的

所发布的应用程序包含下列 Google SDK，可能在使用应用程序或连上网络时自动处理信息。实际范围取决于 SDK 版本、设备与地区设置、同意状态及 Google 服务组态。

所有年龄的更新检查都可能使用独立的 Firebase Remote Config 与 Firebase Installations 服务。为了发送设置并提供此功能，会处理更新专用的安装识别码、验证权杖、应用程序版本、语言、操作系统，以及连接所使用的 IP 地址。此处理与选用的使用分析及崩溃报告分开；更新检查不会激活 Analytics、Crashlytics 或广告 ID 搜集。我们不使用广告或分析用的用户属性、实验或个人化设置。

服务可能处理的信息目的
Google AdMob / Google Mobile AdsIP 地址及由此推估的大概位置；Android 广告 ID、应用程序组 ID 与其他设备或账号相关识别码；启动应用程序、广告曝光、点击及视频观看等交互；应用程序与广告 SDK 的性能及诊断信息。受保护的广告请求会应用儿童处理设置，防止发送 Android 广告 ID。投放与衡量非个性化广告；安全与防范欺诈
Google User Messaging Platform（UMP）地区与设备信息、同意状态、广告隐私选择，以及应用选择所需的识别码与设置信息显示必要的广告同意消息、保存选择并应用至广告请求
Google Analytics for Firebase仅限主动同意的成人：应用程序运行个体或安装识别码、设备型号、操作系统、应用程序版本与语言、工作阶段或画面事件，以及 SDK 处理的 IP 或大致地区信息。Analytics 的广告 ID 搜集、广告保存、广告用户数据及广告个人化信号均停用。 分析数据还包括游戏与关卡活动、游戏成绩与重试、广告展示及设置变更。了解使用情况、功能使用与稳定性趋势，以改进服务
Firebase Crashlytics 与 Firebase 安装服务仅限主动同意的成人：安装或工作阶段识别码、崩溃或错误时间与堆栈追踪、错误消息、应用程序版本、操作系统、设备型号、内存等诊断数据，以及关联的崩溃前应用程序事件侦测与调查错误、衡量受影响的安装数并提升可靠性
Firebase Remote Config / Firebase Installations更新专用的安装识别码与验证权杖、应用程序版本、语言、操作系统及连接信息发送及缓存建议与必要版本设置，提供更新功能
Google Play In-App Updates应用程序与设备中继数据、已安装版本、更新状态及错误信息通过 Google Play 检查可用更新、下载、安装及重新启动

我们不将您的姓名、电子邮件或电话设为 Analytics 用户 ID，也不将游戏存档作为分析事件发送。设备与应用程序识别码即使不含真实姓名，仍可能依适用法律属于个人数据。

在年龄判定前，以及对未满 18 岁或年龄不明的受保护用户，不启动 Firebase Core、Analytics 或 Crashlytics。成人可明确选择加入使用情况分析及崩溃报告，并在设置中一起关闭。

4. Google 与其他服务提供商

上述信息可能为了广告、分析及崩溃报告而发送至 Google LLC，以及相关服务条款所列的 Google 关系企业并由其处理。依服务与条款不同，Google 可能作为受托处理者或独立的数据控管者。

依您的地区、选择及广告组态，Google 广告技术提供商可能处理广告请求与衡量信息。若有显示同意消息，请参阅该消息与 Google 相关说明，以了解适用的提供商及选项。

我们通过 Gmail（Google）收取并保存客服电子邮件。邮件提供商可能处理寄件地址、消息与您选择寄送的附件。请仅提供解决问题所需的信息。

我们并未另行经营贩售个人数据的业务。不过，广告相关揭露在某些法律下可能构成「分享」或定向广告处理，请参阅下方选项。为履行法律义务、回应合法要求或办理您的请求，我们也可能揭露有限信息。

5. 广告选择、同意与处理依据

会等到本机年龄判定完成或选择跳过后，才发出广告隐私或广告请求。成人的分析与崩溃报告为自愿同意，缺省不勾选，拒绝不影响任何游戏。在设置中关闭后，会停止后续搜集，并删除设备上尚未发送的崩溃报告，但不会自动删除已发送的记录。

广告 SDK 会在 Google UMP 表示可提出广告请求后才要求广告。依地区及 Google 规定，可能显示广告通知或同意消息。若需要提供隐私选项，您可从应用程序设置中的广告隐私选项重新查看或变更选择；UMP 判定必要时才会显示该项目。

本应用程序要求 G 级、非个性化广告。对未满 18 岁或年龄不明的受保护用户，应用 Google 儿童处理与 UMP 未达同意年龄设置。非个性化或受限广告仍可能处理 IP、大概位置、允许的识别码、交互及诊断信息。拒绝广告同意或广告加载失败都不影响游玩。

您可在 Android 隐私或广告设置中管理可用的广告 ID 选项，例如删除 ID。名称与选项因设备而异。Google 账号的广告控制另于 Google 服务范围内适用。

依适用法律，处理依据可能为提供服务、维持可靠性与安全及改进服务的正当利益、法律义务，或必要时的同意。若基于同意处理，您可撤回同意，不影响撤回前处理的合法性。在要求同意的地区，必须符合相关要求。广告同意与分析、诊断处理的范围彼此独立。

6. 保存与删除

信息保存与删除
本机游戏存档与偏好设置只要数据仍在设备上就会保存。应用程序的进度重设会清除该功能涵盖的关卡完成、星星及其他进度记录；偏好、部分最高分及 SDK 数据可能保留。若要移除本机数据，请在 Android 设置中清除应用程序保存空间。卸载、备份保留及还原取决于设备与备份设置。
Analytics 数据依 Analytics 资源的保存设置及删除进程处理。标准 GA4 通常提供用户或事件层级 2 个月或 14 个月的设置，依活动更新期限及其他设置可能影响保存期间。这些限制并非以相同方式适用于所有标准汇总报表，汇总统计可能保留更久。
Crashlytics 数据Google 说明，崩溃堆栈追踪与相关识别码保存 90 天后，才开始从正式及备份系统移除的进程，并不表示第 90 天便完成删除。
广告与同意数据依 Google 与相关提供商的保存及删除政策，在广告投放、衡量、防范欺诈与尊重选择所需的期间内处理。本机同意设置与提供商记录的保存期间可能不同。
客服电子邮件保存至问题与必要后续处理完成后删除。若法律要求保留，仅将必要信息保存至法定期限。
Google Play 游戏备份与服务数据记录存于 Google 账号的 Saved Games，并依 Google 的保留及删除进程处理。可在 Android 的 Google 设置中管理登录账号，并通过 Play 游戏个人资料或 Google 账号的游戏数据管理删除本游戏数据。卸载或重设本机进度不会删除云端副本；维持连接时，记录可能再次合并回来。

清除应用程序数据或卸载不会立即删除已发送给 Google 的信息。如欲对已发送信息行使权利，请联系我们或使用相关的 Google 隐私控制。

7. 国际处理与传输

使用 Google 服务可能涉及在您所在国家以外保存及处理数据，包括美国及 Google 或相关提供商设有设施的其他国家。接收者包括 Google LLC，以及相关条款及政策所列的关系企业或受托处理者。处理地点依 Google 数据处理条款及设施信息而定。

信息与目的如自动搜集及提供商章节所述，包括广告、分析、崩溃诊断及电子邮件支持。传输在使用 SDK 时通过网络进行。保存依本政策保存章节及相关提供商政策办理。Google 隐私权政策提供其隐私联系管道。

法律要求时，须有适当的传输依据，例如同意或契约保障。若对传输有疑问或异议，请联系我们的隐私联系邮箱。广告选择可通过相关消息与应用程序设置管理。成人亦可在设置中停止自愿的分析与崩溃报告；受保护用户不适用此类搜集。

8. 您的权利与代理人

依适用法律，您可请求查阅或取得副本、更正、删除、限制处理、提出异议、撤回同意、数据可携，或行使定向广告相关选择。法律允许时，父母、监护人或其他授权代理人可代为行使。

我们不营运自有会员账号，也不保有安装识别码与真实姓名、电子邮件的对照表。选用的 Play 游戏连接及删除由 Google 提供管理功能。仅凭电子邮件可能无法找出特定安装的 SDK 记录。我们会在合理可行范围内协助确认记录，并说明服务提供者的管理途径。仅要求处理请求所需的数据，请勿发送不必要的身分证号或敏感信息。

您可向所在地的个人数据保护机关申诉。在韩国可向个人信息侵害申告中心（privacy.kisa.or.kr，韩国境内 118）或个人信息纷争调停委员会（kopico.go.kr，韩国境内 1833-6972）寻求协助。

mozzink.support@gmail.com

9. 儿童与未成年人

本应用程序适合所有年龄。对未满 18 岁及未填写出生日期者采取审慎的保护措施。出生日期仅用于本机年龄判定，不保存或发送。所有年龄都可使用全部游戏。不会预选成人年龄，也不会将成年设为获得游戏权益的条件。

受保护的用户不会启动 Firebase 分析或崩溃报告 SDK。广告使用 Families 自我认证版本范围内的 Google Mobile Ads，并采用 G 级、非个性化及适合儿童的广告设置。受保护用户的 Android 广告 ID 不会发送。这些设置不会消除情境广告投放及安全所需的所有网络处理，请参阅上述 SDK 说明。

儿童数据、家长许可与额外保护的适用规定仍须遵守。家长或监护人若对儿童数据或未取得必要许可的处理有疑虑，可联系我们的隐私联系邮箱。我们会在合理可行的范围内调查，并采取必要的删除、限制或其他措施。

10. 安全措施

我们将服务管理账号及个人数据的访问限制在必要范围，并采取适当保护措施，例如提供商的安全功能及传输加密。本机信息受操作系统的应用程序保存保护。不再需要的信息会依相关保存与删除进程删除或去识别化。

请勿在客服请求中提供非解决问题所需的密码、政府识别码、付款数据或其他敏感信息。

11. 本政策网站

本页没有开发者设置的广告、访客分析 SDK、追踪程序或追踪 Cookie，并由 GitHub Pages 托管。GitHub 可能依其隐私声明，为安全等目的处理访客 IP 地址与其他连接信息。点击外部政策连接后，适用该提供商网站的政策。

应用程序会向 GitHub Pages 检查关卡内容更新，并下载已变更的游戏数据。这些请求不会附带 Play 游戏账号信息或个人游玩记录。GitHub 可能依其隐私权声明，为提供内容及维护安全而处理 IP 地址等一般连接信息。
